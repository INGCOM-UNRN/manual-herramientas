# Ciclo de Trabajo Docente

El ciclo docente de la cátedra de Programación 1 articula de forma continua y automatizada las cinco etapas del dictado universitario:

1. **Planificación y Autoría Didáctica**: Diseño de guías de trabajos prácticos, asignación de niveles Bloom y control de sobrecarga horaria (`deckard`, `myst-tools`, `tyrell`).
2. **Autoría de Evaluaciones**: Generación de variantes procedurales anti-copia con compilador GCC embebido (`idkfa`), maquetación de exámenes presenciales con OMR (`alucarD`) y normalización de bancos GIFT/XML (`voight`).
3. **Ingesta y Recepción**: Descarga masiva de entregas de Moodle ZIP (con desempaquetado recursivo, aplanado y normalización UTF-8) y clonado ordenado de GitHub Classroom (`dredd`).
4. **Evaluación Masiva y Auditoría**: Ejecución batch de suites de prueba, chequeo estático y AST, y análisis de similitud Winnowing (`dredd eval`, `dredd plagiarism`, `weyl`).
5. **Devolución y Cierre de Actas**: Publicación automática de informes en Pull Requests de GitHub, exportación CSV para Moodle y generación de guías para coloquios orales (`dredd github comment`, `dredd export`, `dredd oral-guide`).
